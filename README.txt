# Телефонная книга

Настольное приложение на Python (Tkinter) для ведения телефонного справочника
с хранением данных в JSON-файле.

Проект построен по архитектурному паттерну **MVC** (Model–View–Controller):
модель данных, интерфейс и управляющая логика полностью разделены.

---

## Возможности

- 📂 **Загрузка** справочника из JSON-файла.
- 💾 **Сохранение** в JSON-файл (в т.ч. «Сохранить как…»).
- ➕ **Добавление** нового контакта.
- ✏️ **Редактирование** существующего контакта (двойной клик по строке).
- 🗑 **Удаление** контакта с подтверждением.
- 🔍 **Поиск** по имени, телефону и комментарию (без учёта регистра).
- 🔃 **Сортировка** по любому столбцу (повторный клик — обратный порядок).
- 📱 **Автоформатирование телефона** по маске `+7 XXX XXX-XX-XX`
  с валидацией в реальном времени.
- 🚫 **Ограничения ввода**: длина полей и допустимые символы имени.
- 🔢 **Лимит записей** — не более 100 контактов в справочнике.
- ⚠️ **Защита от потери данных**: при закрытии окна с несохранёнными
  изменениями предлагается сохранить их.
- 🆕 **Создание нового справочника** прямо из кнопки «Добавить»,
  если файл ещё не загружен.

## Архитектура (MVC)
┌──────────────────────────────────────────────────────────┐
│ main.py │
│ (точка входа) │
└───────────────────────────┬──────────────────────────────┘
│
▼
┌──────────────────────────────────────────────────────────┐
│ controller.py │
│ PhoneBookController │
│ связывает события UI с операциями модели │
└───────────────┬──────────────────────────┬───────────────┘
│ │
▼ ▼
┌───────────────────────────┐ ┌───────────────────────────┐
│ view.py │ │ model.py │
│ │ │ │
│ PhoneBookView │ │ Contact │
│ ContactDialog │ │ PhoneBook │
│ PhoneEntry │ │ FileReader │
│ limit_length / limit_name │ │ FileWriter │
│ │ │ + кастомные исключения │
│ │ │ + валидация телефона │
└───────────────────────────┘ └───────────────────────────┘


- **Model** (`model.py`) — не зависит от Tkinter, легко тестируется.
- **View** (`view.py`) — только отрисовка и взаимодействие с пользователем,
  общается с контроллером через `callbacks`.
- **Controller** (`controller.py`) — оркестратор: принимает события
  от View, вызывает Model, обновляет View.

## Запуск

### Требования

- **Python 3.10+** (используется синтаксис `str | None`, `list[Contact]`).
- **Tkinter** — входит в стандартную библиотеку Python.
  На Linux может потребоваться установка:

  ```bash
  # Debian/Ubuntu
  sudo apt install python3-tk

  # Fedora
  sudo dnf install python3-tkinter

  # Arch
  sudo pacman -S tk

Запуск приложения
  python main.py

Формат файла данных
JSON-файл со списком контактов:
{
  "contacts": [
    {
      "name": "Иван Иванов",
      "phone": "+7 900 123-45-67",
      "comment": "Телефон Ивана"
    },
    {
      "name": "Петр Петров",
      "phone": "+7 900 765-43-21",
      "comment": "Телефон Петра"
    }
  ]
}

Каждая запись содержит поля:

Поле	Тип	Описание
name	строка	Имя контакта (до 64 символов)
phone	строка	Телефон в формате +7 XXX XXX-XX-XX
comment	строка	Произвольный комментарий
🧩 Основные классы
Модель (model.py)
Класс / функция	Назначение
Contact	Одна запись справочника. to_dict() / from_dict()
PhoneBook	Контейнер контактов: add/remove/edit, поиск, сортировка, лимит
FileReader	Загрузка контактов из JSON (FileReader.read)
FileWriter	Сохранение контактов в JSON (FileWriter.write, create_empty)
is_valid_phone	Проверка строки по строгой маске телефона
normalize_phone	Приведение произвольного ввода к формату +7 ...
extract_digits	Извлечение «полезных» цифр номера
Представление (view.py)
Класс / функция	Назначение
PhoneBookView	Главное окно: панель, поиск, таблица, статусбар
ContactDialog	Модальное окно добавления/редактирования контакта
PhoneEntry	Поле телефона с автоформатированием и валидацией
limit_length	Ограничение длины поля ввода
limit_name	Ограничение длины + фильтр символов для имени
Контроллер (controller.py)
Класс	Назначение
PhoneBookController	Обрабатывает события UI, вызывает модель, обновляет вид
⚠️ Кастомные исключения
Все исключения проекта наследуются от PhoneBookError (model.py):

Исключение	Когда возникает
PhoneBookError	Базовое исключение проекта
FileReadError	Ошибка чтения / парсинга JSON-файла
FileWriteError	Ошибка записи файла
ContactLimitError	Превышен лимит записей (100)
ContactNotFoundError	Запрашиваемый контакт не найден
InvalidPhoneError	Неверный формат телефона
Контроллер перехватывает эти исключения и показывает пользователю
понятное сообщение через messagebox, не роняя приложение.

🎯 Сценарии работы
Создание нового справочника
Нажмите ➕ Добавить.

Поскольку файл ещё не загружен, откроется диалог выбора пути —
укажите имя и место нового JSON-файла.

Заполните форму контакта и нажмите Сохранить.

Не забудьте нажать 💾 Сохранить, чтобы записать данные на диск.

Загрузка существующего справочника
Нажмите 📂 Загрузить.

Выберите .json-файл в формате, описанном выше.

Контакты появятся в таблице.

Редактирование контакта
Выделите строку и нажмите ✏ Изменить,
либо дважды кликните по строке.

Поиск
Начните вводить текст в поле Поиск — таблица фильтруется
в реальном времени по имени, телефону и комментарию.

Сортировка
Кликните по заголовку столбца. Повторный клик меняет направление.

Ограничения
Ограничение	Значение
Максимум записей в справочнике	100
Максимальная длина имени	64
Максимальная длина комментария	64
Допустимые символы имени	буквы (RU/EN), пробел, дефис, апостроф
Формат телефона	+7 XXX XXX-XX-XX
